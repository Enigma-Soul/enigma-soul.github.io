Loop / Recursion method

This method is too slow, but the logic is simple. Time complexity O(n)O(n)O(n) - very slow.

int sum(int n){
    int ans = 0;
    for(int i = 1;i<=n;i++){
        ans += i;
    }
    return ans;
}

Formula method

This is clearly an arithmetic series, so:

S=(n+1)n2 S = \frac{(n+1)n}{2} S=2(n+1)n​

In this formula, (n+1)n(n+1)n(n+1)n is too large. Rearranging slightly:

S=(n+12)n S = (\frac{n+1}{2})n S=(2n+1​)n

This reduces the risk of overflow. If you don’t cast to double, remember to check the parity of n.
